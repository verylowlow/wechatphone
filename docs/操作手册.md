# wechatphone 操作手册

> 适用版本基线（2026-08-10 实测）：微信 4.1.12.26（Weixin.exe）、企业微信（WXWork.exe）、钉钉（UIA 方案，未实测）。
> 配套文档：`docs/测试手册.md`；原理与配置全表见根目录 `README.md`。

---

## 1. 系统组成

| 模块 | 入口 | 说明 |
|---|---|---|
| 音频桥接 + AI 通话 | `bridge.py` | loopback 捕获对方声音 → 阿里云 Realtime；AI 语音写入 CABLE Input |
| 知识库管理 | `kb_app.py` | http://127.0.0.1:8765，上传/置顶/检索测试 |
| 通话记录 | `calllog_app.py` | http://127.0.0.1:8766，通话列表与时间线 |
| 自动拨号 | `autodial.cli` / `autodial_app.py` | http://127.0.0.1:8767，单个/批量 UI 自动化拨号 |

支持应用端：`--app wechat`（默认）/ `--app wecom` / `--app dingtalk` / `--manual`（纯音频，任何 App 零适配）。

## 2. 环境准备

1. 安装 VB-Cable，确认系统存在 `CABLE Input`（输出端）与 `CABLE Output`（输入端）。
2. 依赖安装（`.venv` 已建好则跳过）：
   ```bash
   .venv\Scripts\python.exe -m pip install -r requirements.txt
   ```
   视觉自动化依赖：`opencv-python-headless`、`rapidocr-onnxruntime`、`pyautogui`、`pyperclip`。
3. 配置 `.env`（API Key、音色、VAD、知识库、通话记录、开场白等，全表见 README）。

### 应用端音频设置（关键）

| 应用 | 扬声器 | 麦克风 |
|---|---|---|
| 微信 | 本机物理扬声器 | 跟随系统默认（bridge 启动自动切到 `CABLE Output`） |
| 企业微信 | 应用内选物理扬声器 | 应用内选 `CABLE Output` |
| 钉钉 | 应用内选物理扬声器 | 应用内选 `CABLE Output` |

> 系统默认输出**不要**设成 CABLE Input。

## 3. 启动服务

```bash
# 终端1: 音频桥 (必须先起, 批量拨号依赖它的通话记录判断上一通是否结束)
.venv\Scripts\python.exe bridge.py --app wecom        # 或 wechat / --manual

# 终端2 (可选): 拨号 Web 界面
.venv\Scripts\python.exe autodial_app.py              # http://127.0.0.1:8767
```

## 4. 单个拨打与"通话任务"下达

### 4.1 命令

```bash
.venv\Scripts\python.exe -m autodial.cli dial 高原 --app wecom \
    --task "回访确认收货, 引导好评" \
    --opening "高总您好, 我是XX公司的小李" \
    --note "备注: 重点客户"
```

### 4.2 参数说明

| 参数 | 必填 | 作用 |
|---|---|---|
| `contact`（位置参数） | 是 | 联系人名，精确匹配通讯录搜索结果 |
| `--app` | 否 | `wechat` / `wecom` / `dingtalk`，默认 `wechat` |
| `--task` | 否 | **通话核心目的**，注入 AI 的 instructions（system prompt） |
| `--opening` | 否 | **开场白**：AI 接通后第一句话；缺省回退 `.env` 的 `OUTBOUND_DEFAULT_OPENING` |
| `--note` | 否 | 备注，随任务透传 |
| `--dry-run` | 否 | 走全流程但不实际点击（预演） |

只拨号不下任务：省略 `--task`/`--opening` 即可（AI 用基础人设通话）。

### 4.3 任务下达机制（current_task.json）

拨号前 autodial 会写 `data/current_task.json`，`bridge.py` 轮询到后动态
`session.update` 把任务拼进 instructions：

```json
{
  "app": "wecom",
  "contact": "高原",
  "task": "回访确认收货, 引导好评",
  "note": "备注: 重点客户",
  "opening": "高总您好, 我是XX公司的小李",
  "seq": 1786336152876,
  "written_at": "2026-08-10 14:30:00"
}
```

- `seq` 为毫秒时间戳，bridge 用它判断文件是否更新；通话记录收尾时自动清零还原。
- AI 行为：接通后数秒无人出声（`OUTBOUND_OPEN_DELAY`，默认 5s）AI 先说**开场白**，
  随后围绕 **★核心目的（task）** 主动推进对话。
- 来电开场白走另一通道：`.env` 的 `INCOMING_GREETING` 固定文案。

### 4.4 Web 方式

`autodial_app.py` 页面：选应用 → 填 联系人/任务/开场白 → 拨号；
批量区每行一条：`联系人名|任务|开场白`（后两段可省）。

## 5. 批量拨打

### 5.1 名单文件（两种格式）

`names.txt`（一行一个名字，共享 `--task`）：

```text
高原
张三
李四
```

`tasks.json`（每人独立任务/开场白）：

```json
[
  {"contact": "高原", "task": "回访确认收货", "opening": "高总您好"},
  {"contact": "张三", "task": "通知明天活动"}
]
```

### 5.2 命令

```bash
# 纯文本名单 + 共享任务
.venv\Scripts\python.exe -m autodial.cli batch names.txt --app wecom --task "统一回访"

# JSON 名单 + 批次共享开场白 (单条自带 opening 时优先单条)
.venv\Scripts\python.exe -m autodial.cli batch tasks.json --app wecom --opening "您好, 打扰一分钟"

# 可选: --gap 30 无通话记录时两通间隔秒数; --timeout 600 单通等待结束超时; --dry-run 预演
```

批量逻辑：拨下一个前，读 `data/calls.sqlite` 等上一通**真正结束**（或超时），带 2s 喘息。

## 6. 各应用拨号流程（UI 自动化 SOP）

### 微信（4.1+，vision41）

激活主窗 → 左栏【通讯录】图标 → 搜索栏清除+粘贴 → OCR 校验（同名多条→终止并记入通话记录）
→ 点完全命中第一条 → 右上【语音通话】→ 下拉菜单**第一项**（第二项是视频，勿点）。
挂断=通话窗口大红圆；接听=来电窗口大绿圆。

### 企业微信（wecom_vision，2026-08-10 实测）

1. 激活 `WeWorkWindow` 主窗口；
2. 点击左栏第 10 项【通讯录】（OCR 找文本行自校正，回退坐标 (135,738)）；
3. 点击搜索框（≈(500,75)）→ Ctrl+A/Delete 清除 → 剪贴板粘贴精确用户名；
4. 点击中间列表查询结果第一条（过滤区排除右侧面板同名标题）；
5. 点击客户面板明显的【语音通话】按钮（OCR 优先，回退 (1739,658)）；
6. 进入呼叫界面（"正在呼叫"）；
7. 点击界面下方**大红圆**（红连通域，回退 OCR【挂断】）挂断。

> 企微两个坑：① 点左上头像区会弹账号菜单且点别处不关闭，只能 Escape（会隐藏主窗，
> 程序已内置检测+重激活兜底）；② 截图预览有非等比缩放，改坐标必须用 OCR/像素实测，勿目测。

### 钉钉（UIA 方案，未实测）

按按钮名定位（校准 `calibrate --app dingtalk`）；若 UIA 抓不到控件（自绘界面），
退路是 `--manual` 纯音频模式手动拨接。

## 7. 来电自动接听与 AI 挂断

- `bridge.py` 内置来电监听：发现接听按钮/大绿圆即自动接听（视频默认不接，`AUTO_ANSWER_VIDEO=1` 放开）。
- AI 判定结束（对方说"挂了/拜拜"）→ 调 `hang_up` 工具 → 播完道别语 → 点挂断 → 收尾通话记录。
- 临时关自动接听：`bridge.py --no-auto-answer`。

## 8. 注意事项

- 拨打时**勿动鼠标键盘**（真实坐标点击）。
- 换应用/换版本/改窗口布局后需重新校准（视觉方案坐标见 `autodial/wx41.py`、`autodial/wecom_ui.py` 顶部常量）。
- 单实例单通话：一路 bridge 只服务一个应用端的一路通话，切换应用需重启。
- 批量拨打务必先起 `bridge.py`（否则用固定间隔等待）。
- IDE 等置顶窗口会遮挡点击，程序会自动最小化 WorkBuddy 置顶窗。
